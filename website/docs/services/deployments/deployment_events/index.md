Get the deployment events for a deployment. Backed by the Railway GraphQL query deploymentEvents.

```sql
SELECT
id,
completed_at,
created_at,
payload,
step
FROM railway.deployments.deployment_events
WHERE id = '{{ id }}' -- required
;
```
