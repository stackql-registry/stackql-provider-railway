Get an invite code for a project for a specifc role. Backed by the Railway GraphQL query projectInviteCode.

```sql
SELECT
id,
project_id,
code,
created_at,
project,
role
FROM railway.projects.project_invite_codes
WHERE project_id = '{{ project_id }}' -- required
AND role = '{{ role }}' -- required
;
```
