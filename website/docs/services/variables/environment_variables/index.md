## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[

<TabItem value="list">

Lists Variable objects of a Environment. Backed by the Railway GraphQL query environment.variables.

```sql
SELECT
id,
name,
environment_id,
service_id,
created_at,
is_sealed,
references_,
updated_at
FROM railway.variables.environment_variables
WHERE environment_id = '{{ environment_id }}' -- required
AND project_id = '{{ project_id }}'
;
```
