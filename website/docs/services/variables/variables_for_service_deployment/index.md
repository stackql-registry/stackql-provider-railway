## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[

All rendered variables that are required for a service deployment. Backed by the Railway GraphQL query variablesForServiceDeployment.

```sql
SELECT
name,
value
FROM railway.variables.variables_for_service_deployment
WHERE environment_id = '{{ environment_id }}' -- required
AND project_id = '{{ project_id }}' -- required
AND service_id = '{{ service_id }}' -- required
;
```
