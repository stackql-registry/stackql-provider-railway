Gets all identity providers of a workspace. Backed by the Railway GraphQL query workspaceIdentityProviders.

```sql
SELECT
id,
workspace_id,
connection,
created_at,
enforcement_enabled_at,
updated_at,
workspace
FROM railway.workspaces.workspace_identity_providers
WHERE workspace_id = '{{ workspace_id }}' -- required
;
```
