## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Lists ProviderAuth objects of a User. Backed by the Railway GraphQL query me.providerAuths.

```sql
SELECT
id,
user_id,
email,
is_auth_enabled,
metadata,
provider
FROM railway.account.provider_auths
;
```
</TabItem>
</Tabs>
