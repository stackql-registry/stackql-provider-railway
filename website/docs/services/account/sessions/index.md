## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Gets all sessions for authenticated user. Backed by the Railway GraphQL query sessions.

```sql
SELECT
id,
name,
created_at,
expired_at,
is_current,
type,
updated_at
FROM railway.account.sessions
;
```
</TabItem>
</Tabs>
