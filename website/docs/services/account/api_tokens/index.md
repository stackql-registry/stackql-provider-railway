## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Gets all API tokens for the authenticated user. Backed by the Railway GraphQL query apiTokens.

```sql
SELECT
id,
name,
workspace_id,
display_token,
expires_at
FROM railway.account.api_tokens
;
```
</TabItem>
</Tabs>

```sql
name,
workspace_id

'{{ name }}' /* required */,
'{{ workspace_id }}'
RETURNING
result
;
```

<TabItem value="delete">

Deletes an API token. Backed by the Railway GraphQL mutation apiTokenDelete.

```sql

;
```
