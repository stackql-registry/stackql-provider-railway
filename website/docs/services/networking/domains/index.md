## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

All domains for a service instance. Backed by the Railway GraphQL query domains.

```sql
SELECT
custom_domains,
service_domains
FROM railway.networking.domains
WHERE environment_id = '{{ environment_id }}' -- required
AND project_id = '{{ project_id }}' -- required
AND service_id = '{{ service_id }}' -- required
;
```
</TabItem>
